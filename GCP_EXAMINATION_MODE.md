# GCP Examination Mode

GCP Qualification imports one immutable task while the Workbench has no other active task. The record binds examination ID, examiner Sol, candidate Lil Tweak, project, candidate service account, region, zone, ceiling, task number, task digest, and source digest.

Every permitted cloud command uses `gcloud` and must include:

- the authorized project;
- keyless impersonation of the candidate service account;
- the authorized region or zone when the command is regional or zonal;
- task-scoped network mode;
- exact inclusion in the approved plan.

The broker denies direct HTTP and `kubectl` cloud access as well as service-account keys, raw token
retrieval, other projects, project deletion, billing and budgets, organization and folders, Owner or
Editor grants, audit-log weakening, examiner identity changes, production data, and internet-wide
administrative exposure.

No GCP execution provider is implemented. These policy checks are offline guards and do not prove
candidate identity, project confinement, network confinement, or cloud execution.

The interface contains no task answers, scoring logic, hidden faults, or future tasks. Completion evidence is candidate evidence for Sol to examine later; it is not Sol's independent verification.
